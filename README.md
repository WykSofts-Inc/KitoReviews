# KitoReviews

Star ratings, rating summaries, review cards, a review composer and a polite review prompt for
SwiftUI. Part of the [Kito](https://github.com/WykSofts-Inc/KitoDevKit) ecosystem.

## Installation

```swift
.package(url: "https://github.com/WykSofts-Inc/KitoReviews.git", from: "0.1.0")
```
